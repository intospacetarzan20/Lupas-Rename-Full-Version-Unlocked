## Main Features
<a id="main-features"></a>

### Core Functionality
- **Automatic Renaming** — Automatically rename files by applying various operations, such as replacing text, inserting characters, or changing letter cases. This ensures that your files are named according to your specific preferences with minimal effort.
- **Batch Processing** — Process a large number of files simultaneously, saving time and enhancing productivity. Users can select multiple files or entire folders and apply the same renaming rules across all selected items.
- **Recursive Mode** — Execute renaming actions not only on selected files but also on all files within subdirectories. This feature is particularly useful for organizing deeply nested folders.
- **Advanced Filters** — Use filters to display files based on criteria like size, name length, or modification dates. This helps users target specific files for renaming easily.
- **Context Menu Integration** — Access Lupas Rename directly from the Windows Explorer context menu, making it easy to start renaming files without additional navigation.

### Advanced Capabilities
- **File Numbering** — Automatically number files in binary, decimal, octal, or hex formats. This feature is helpful for organizing files in a sequential manner.
- **Undo Functionality** — Revert changes made in the last renaming operation with the built-in "UNDO" option. This safety net allows users to experiment with different naming conventions without the fear of making irreversible mistakes.
- **Mask Usage** — Utilize masks to define search parameters for files, enabling more precise renaming processes. This is particularly useful for filtering files based on naming patterns.
- **Hidden File Management** — Configure the software to show hidden or read-only system files, ensuring that all relevant files can be renamed as needed.
